貪食蛇隱私權政策

最後更新：2026-09-21

資料收集

本遊戲不要求建立帳號，也不收集、出售或分享可識別個人身分的資料。遊戲不使用廣告、分析 SDK、定位、相機、麥克風、聯絡人或背景追蹤。

本機資料

最高分、統計、成就、設定、語言與主題偏好僅儲存在使用者裝置的本機儲存空間。刪除 App 或清除 App 資料即可移除這些資料。

分享功能

只有在使用者主動選擇分享時，App 才會產生戰績圖片並交由作業系統的分享功能處理。遊戲不會自動上傳或保存分享內容。

網路與第三方服務

Web 版本會從 GitHub Pages 載入遊戲資源；原生 App 將資源內建於 App，可離線遊玩。專案使用 Capacitor 與 Electron 作為封裝工具，不代表遊戲會將資料傳送給這些服務。

聯絡方式

如有隱私問題，請透過 GitHub Issues 聯絡。
